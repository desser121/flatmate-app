# Product Requirements Document

## Название приложения

暂未确定 (working name: **FlatMate**)

## Идея

Tinder-подобное приложение для поиска жилья и соседей. Не каталог объявлений, а персональный подбор: человек ↔ человек ↔ жильё. Механика свайпов и рекомендаций вместо длинных списков.

## Целевая аудитория

Все люди, которым нужно найти жильё или соседа:
- Студенты
- Рабочие/мигранты
- Релоканты
- Люди, переезжающие в другой город
- Те, кто снимает жильё и ищет соседа
- Те, кто сдаёт жильё

## География

Вся Россия. Русский язык интерфейса.

## Роли пользователей

Один пользователь может выполнять несколько ролей одновременно:
- **Ищу жильё** — ищу квартиру/комнату для аренды
- **Ищу соседа** — уже снимаю жильё ищу человека для совместной аренды
- **Сдаю жильё** — у меня есть жильё, которое я хочу сдать

## Типы жилья

- Комнаты в квартирах
- Целые квартиры
- Дома
- Койко-места
- Совместная аренда

## Ключевые сущности

### User (Пользователь)
- ID
- Телефон (для входа)
- Пароль (хешированный)
- Имя
- Дата рождения
- Пол
- Фото профиля (обязательно для использования свайпов, опционально при регистрации)
- Город
- Роль (ищу жильё / ищу соседа / сдаю жильё)
- Дата создания
- Дата обновления

### Listing (Объявление)
- ID
- Автор (User)
- Тип (сдаю жильё / ищу жильё / ищу соседа)
- Тип жилья (комната / квартира / дом / койко-место)
- Город
- Район
- Адрес
- Бюджет (от-до)
- Описание
- Дата создания
- Дата обновления

### ListingPhoto (Фото объявления)
- ID
- Listing
- URL
- Порядок
- Дата создания

### Preference (Предпочтения пользователя)
- ID
- User
- Город
- Район
- Бюджет (от-до)
- Пол (предпочтение)
- Возраст (от-до)
- Курение
- Животные
- График жизни (сова/жаворонок)
- Срок аренды
- Интересы

### Swipe (Свайп)
- ID
- Автор (User)
- Объект типа (User или Listing)
- Объект ID
- Тип (Like / Dislike)
- Дата создания

### Match (Совпадение)
- ID
- User 1
- User 2
- Listing (опционально — если совпали по жилью)
- Дата создания

### Conversation (Чат)
- ID
- Match
- Дата создания
- Дата последнего сообщения

### Message (Сообщение)
- ID
- Conversation
- Автор (User)
- Текст
- Тип (текст / фото / документ)
- URL вложения
- Дата создания
- Прочитано

### Viewing (Просмотр жилья)
- ID
- Match
- Дата просмотра
- Статус (запланирован / проведён / отменён)
- Заметки

## Сценарии использования

### Сценарий 1: Поиск соседа
```
Регистрация
    ↓
Создание профиля (фото обязательно)
    ↓
Установка предпочтений
    ↓
Получение рекомендаций людей
    ↓
Swipe на людей
    ↓
Взаимный Like → Match
    ↓
Чат
    ↓
Вместе ищем жильё
```

### Сценарий 2: Поиск жилья
```
Регистрация
    ↓
Создание профиля
    ↓
Установка предпочтений
    ↓
Получение рекомендаций жилья
    ↓
Swipe на варианты жилья
    ↓
Взаимный Like (сдающий + ищущий) → Match
    ↓
Чат
    ↓
Договор о просмотре
```

### Сценарий 3: Сдача жилья
```
Регистрация
    ↓
Создание профиля
    ↓
Создание объявления (фото обязательно)
    ↓
Получение рекомендаций людей
    ↓
Swipe на людей
    ↓
Взаимный Like → Match
    ↓
Чат
    ↓
Просмотр
    ↓
Встретились ✓
```
